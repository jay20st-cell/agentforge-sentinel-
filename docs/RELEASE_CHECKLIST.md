## K. Automated gates

Before Arena binding:

```bash
pytest
sentinel-preflight --static
```

After organizer values are received and configured:

```bash
sentinel-preflight
```

A non-zero exit from `sentinel-preflight` is a release blocker. Warnings require an explicit decision; BLOCK findings do not.
